

# Project name

Movie information APP

Author: Janni Virta


### Project idea

The website is meant for searching information about movies being shown at Finnkino.

### Planned features

-Dropdown list to select a theater
-Pictures and information about the movies shown

## Web links

- **Published application:** https://sparkling-gaufre-504908.netlify.app
- **GitHub repository:** https://github.com/Janniiiv/Project2a.git
- **Project video presentation:** https://video.laurea.fi/media/t/0_a8zmy8pe

## About the application

The application should show what movies are playing in a selected Finnkino theater.

## Technologies

Describe the technologies you used and their role in your project.

- HTML – page structure
- CSS – styling and layout
- JavaScript – AJAX

## How to use the application


1. Open the published application using the link above.
2. Choose the movie theater from the drop down menu
3. You will see movies that are being shown in the selected theater
